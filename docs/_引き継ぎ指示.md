## 読者像（これを外すと全部ずれる）

**読者は「初心者に毛が生えた程度」の一人。**
プログラミングの基礎文法とターミナル操作はできるが、
**Linux カーネルの機能（namespace / cgroup / マウント）の予備知識はほぼゼロ**。
`docker run` は使ったことがあるが、中で何が起きているかは知らない。

**この一人が、初級から始めて最後には高度な部分まで「暗記ではなく理解」できること**が唯一の成功条件。
つまずいたら読者のせいではなく、**階段の一段が高すぎた教材のせい**。段差を見つけたら段を増やす。

## 数値・コマンド出力の出典

**教材に載せる数値とコマンド出力は、すべて実測である。憶測で書いたものは1つも無い。**
出典は次の2つ。**新しい数値を足すときは、必ず先に自分の環境で実測してから書くこと。**

- `../00_smoke_test.md` — 疎通実験の生の出力（カーネル・cgroup・overlayfs・レジストリ）
- `../03_implementation.md` — 実装中に取った出力（脱獄の再現・上限の対照実験・E2E の結果）

主要な実測値（2026-08-03 / Linux 6.18.5 / x86_64）:

| 項目 | 値 |
|---|---|
| ホストのプロセス数 | 85 個 |
| コンテナ内の `ps` | 2 行（ヘッダ + PID 1） |
| PID 名前空間あり・`/proc` 貼り直しなしの `ps -e` | **87 個**（ホストより多い） |
| コンテナの起動時間 | 12〜15 ms（ホストで `/bin/true` 直実行は 3 ms） |
| alpine のレイヤ | 1 枚 / 圧縮 3.67 MiB / 展開後 8.7 MB / 516 ファイル |
| alpine のバージョン | 3.24.1 |
| メモリ上限超過時の終了コード | 137（= 128 + SIGKILL） |
| E2E テスト | 56 項目すべて通過 |

## 執筆の規約（章を追加・修正するとき）

1. **`aside.spine` は全ページで完全一致。** `current` の位置だけを動かす
2. **コードは `src/` と一字一句一致。** 省略は `// …（後のステップで）` と明示する。
   **掲載コードを変えたら該当章も同期する**
3. **`pre.term` の出力は実測のものだけ。** プロンプトは `<span class="ps">`、出力全体を1つの `<span class="out">` で包む
4. **`.ascii` は `white-space:pre`。** 開始タグの直後から図を始め、閉じタグは最終行の末尾に直付けする
5. **落とし穴は先回りする。** `Unshareflags` 漏れ、`/proc` 再マウント漏れ、`lowerdir` の順序、
   マニフェストリスト、whiteout は `.box.hazard` で**読者が踏む前に**警告する
6. **素朴案の破綻から必然を導く。** いきなり正解を出さない
7. **各ステップに「動かして確認」の関所**（`.box.do` + `pre.term`）を置く
8. **章末は FAQ → 理解度チェック → 完了の合図 → まとめ（3段落）→ pager** の順
9. **1章あたり 57KB 以上**
